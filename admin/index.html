0 · Muat master awal (sekali)

Server belum punya master. Pilih semua file dari folder MASTER BARU di Mac: isi data/ (rilis.csv.gz, so.csv.gz, target_ekspeditur.csv.gz, target_distributor.csv.gz) dan config/ (settings.json, ekspeditur_map.json, so_frozen_attrib_master_lama.json). Hanya bisa dilakukan sekali; file disimpan di R2 privat.

1 · Update data

Pilih file ekspor apa adanya (.xlsx). File langsung diunggah; tekan Proses update setelah semua file yang kamu butuhkan terunggah. Harian: Rilis + SO. Awal bulan: tambah Tactical + SNOP + Monitoring (ketiganya sekaligus). Upload ulang hari yang sama aman: SPJ/SO yang sama menggantikan, tidak digandakan.
Selesai ±5–15 menit (file Rilis besar). Data hari ini disembunyikan (situs s.d. H-1). Jika gagal, dashboard tetap versi terakhir yang berhasil dan master tersimpan tidak berubah.
